# lost-and-found-website-project

Made for 2025-2026 FBLA Website Coding and Development

**Overview**
This website simulates a lost-and-found page of a school, allowing students to see and/or upload posts of lost and found items. 

**Real World Scenario**
This website solves the real world senario of students requiring to physically check the lost-and-found area, which may result in time delay, carelessness in search, and other circumstances that results in negative consequences. 

**Features**
1. See a list of lost and/or found items
2. Search through the list using a keyword
3. Post a lost/found item
4. Sign in (Unrequired to post/view items but speeds up the process)
5. Allow admin accounts to manage (delete and/or approve) posts

    * Flask
        * Flask-Mail
        * Werkeug

    * Jinja2
    * JavaScript (Minimal)
* Frontend:
    * HTML5
    * CSS3
    * Bootstrap 5
* Git & Github

**How to run locally**
1. Download repository
2. Open using Visual Code Studio or similar IDE
3. Create a Virtual Environment
4. Install dependencies from requirements.txt
5. Activate Virtual Environment
6. Run app.py using 'python app.py'
